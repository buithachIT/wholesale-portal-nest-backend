# ============================================================
# 4. CẤU TRÚC FEATURE
# ============================================================

Mỗi domain/feature một folder trong `src/`:

```
src/<feature>/
  <feature>.module.ts
  <feature>.controller.ts
  <feature>.service.ts
  <feature>.controller.spec.ts
  <feature>.service.spec.ts
  dto/<name>.dto.ts
```

Ví dụ hiện có: `src/template/`.

Trách nhiệm:

- Controller: HTTP in/out. Không chứa business logic.
- Service: nghiệp vụ và tích hợp (LiquidJS, DB, ...).
- Module: wire `controllers` + `providers`. Export service nếu
  feature khác cần dùng.
- DTO: shape + validate input. Không nhận raw `any` body.

`AppModule` chỉ `imports` feature module. Không nhét logic vào
`AppModule`.

`main.ts` giữ global `ValidationPipe`:

```ts
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    transform: true,
  }),
);
```

# ============================================================
# 5. NAMING
# ============================================================

| Thành phần              | Quy tắc                         | Ví dụ                    |
| ----------------------- | ------------------------------- | ------------------------ |
| File NestJS             | kebab + suffix                  | `template.service.ts`    |
| Class                   | PascalCase                      | `TemplateService`        |
| Method / biến           | camelCase                       | `renderTemplate`         |
| Route                   | plural, lowercase               | `POST /templates/render` |
| JSON API field (DTO)    | camelCase                       | `renderedContent`        |
| DB / field trong docs   | snake_case                      | `credit_limit`           |
| Hằng số / enum value    | UPPER_SNAKE hoặc domain enum    | `SUPER_ADMIN`            |

Identifier trong code: tiếng Anh.
Message lỗi và text user-facing: tiếng Việt.

# ============================================================
# 6. API ENVELOPE
# ============================================================

Success:

```json
{
  "status": "success",
  "data": {
    "result": "..."
  }
}
```

Lỗi: throw NestJS HTTP exception

- `BadRequestException` — input không hợp lệ
- `NotFoundException` — không tìm thấy resource
- `InternalServerErrorException` — lỗi hệ thống (ví dụ render fail)

Không tự `res.status(...).json(...)`.
Không trả `{ ok: true }` hay field lẻ ngoài envelope.

# ============================================================
# 7. DTO & VALIDATION
# ============================================================

Mọi body/query/param phức tạp phải có DTO class + decorator
`class-validator`.

```ts
export class RenderTemplateDto {
  @IsString()
  @IsNotEmpty()
  template!: string;

  @IsObject()
  @IsNotEmpty()
  context!: Record<string, unknown>;
}
```

Controller nhận DTO, không nhận `Record<string, any>` trực tiếp
từ `@Body()`.

# ============================================================
# 8. FORMAT & LINT
# ============================================================

Nguồn sự thật: `.prettierrc` và `eslint.config.mjs`.
Editor: `.editorconfig` + `.vscode/settings.json` (format on save).

Prettier (bắt buộc):

- `singleQuote: true`
- `semi: true`
- `trailingComma: all`
- `printWidth: 80`
- `tabWidth: 2`
- `useTabs: false`
- `bracketSpacing: true`
- `arrowParens: always`
- `endOfLine: lf`

ESLint:

- Flat config + `typescript-eslint` type-checked
- `eslint-plugin-prettier` — lệch Prettier = lỗi
- `no-floating-promises`: error
- `no-unused-vars`: error (`_` được bỏ qua)
- `no-explicit-any` / `no-unsafe-argument`: warn
- Ignore: `dist/`, `node_modules/`, `coverage/`

Không `eslint-disable` / `prettier-ignore` nếu không có comment lý do.

Local (tự sửa):

```bash
npm run format
npm run lint:fix
```

CI / trước khi mở PR (chỉ kiểm, không sửa):

```bash
npm run format:check
npm run lint
npm test
```

Không commit `dist/`, `node_modules/`, `.env`, secret.
