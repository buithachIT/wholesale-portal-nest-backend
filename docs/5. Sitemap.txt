# ============================================================
# 9. ORDER STATUS
# ============================================================

Order.status

pending
│
├── approved
│   │
│   ├── approved_local
│   │
│   └── shipping
│       │
│       └── delivered
│
└── cancelled

Meaning:

pending
Order đã được tạo và đang chờ xử lý.

approved
Order đã được nội bộ phê duyệt.

approved_local
Order đã được phê duyệt nhưng chưa đồng bộ thành công
với shipping carrier.

shipping
Order đang được vận chuyển.

delivered
Toàn bộ logistics của order đã completed.

cancelled
Order đã bị hủy.


# ============================================================
# 10. ORDER PAYMENT STATUS
# ============================================================

Order.payment_status

unpaid
│
├── partial
│   │
│   └── paid
│
└── paid

Calculation:

allocated_amount =
SUM(order_payments.amount_allocated)

allocated_amount = 0
=> unpaid

allocated_amount < order.total_price
=> partial

allocated_amount >= order.total_price
=> paid

Order.payment_status is independent
from Order.status.
