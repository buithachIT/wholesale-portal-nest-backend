# Deploy backend lên VPS

Pipeline: GitHub Actions lint/build trên mỗi PR và `main`. Push `main` SSH vào VPS, `git pull`, `docker compose up --build`. Container chạy `prisma migrate deploy` rồi start API.

## 1. Chuẩn bị VPS (một lần)

Ubuntu, user có quyền Docker (không cần sudo trong script deploy):

```bash
sudo apt update
sudo apt install -y git ca-certificates curl
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker "$USER"
# logout/login lại cho group docker có hiệu lực
```

Clone repo bằng HTTPS (VPS login bằng password, không cần SSH key):

```bash
sudo mkdir -p /opt/wholesale-portal-nest-backend
sudo chown "$USER":"$USER" /opt/wholesale-portal-nest-backend
git clone https://github.com/buithachIT/wholesale-portal-nest-backend.git /opt/wholesale-portal-nest-backend
cd /opt/wholesale-portal-nest-backend
cp .env.example .env
nano .env
```

Trong `.env` trên VPS:

- `POSTGRES_*` và `DATABASE_URL` phải khớp. Host trong `DATABASE_URL` là `postgres` (tên service Compose), không phải `localhost`.
- `JWT_*_SECRET` random dài, khác local.
- `CORS_ORIGIN` = origin frontend (ví dụ `https://app.domain.com`).
- `COOKIE_SAMESITE=none` nếu frontend khác domain; kèm HTTPS.
- `APP_URL` = URL public của API (Swagger).

Chạy lần đầu (chỉ 1 container API, dùng Postgres sẵn có trên VPS):

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

Xem port đang chiếm:

```bash
docker ps --format 'table {{.Names}}\t{{.Ports}}\t{{.Status}}'
```

- Trùng port host → đổi `API_PUBLISH_PORT` trong `.env` (mặc định `3010`, không dùng `3000`).
- `DATABASE_URL` trỏ Postgres đang chạy: host `host.docker.internal`, tạo DB `b2b_logistics_db` trên instance đó.
- Chỉ khi *không* có Postgres: thêm `--profile with-db` (thêm 1 container DB, không publish 5432 ra ngoài).

```bash
docker exec -it TÊN_CONTAINER_POSTGRES psql -U postgres -c "CREATE DATABASE b2b_logistics_db;"
```

API: `http://VPS_IP:3010`.

## 2. GitHub Secrets

Repo → Settings → Secrets and variables → Actions:

| Secret         | Ví dụ                                |
|----------------|--------------------------------------|
| `VPS_HOST`     | IP hoặc domain VPS                   |
| `VPS_USER`     | `root` / `ubuntu`                    |
| `VPS_PASSWORD` | Mật khẩu SSH của user đó             |
| `VPS_PORT`     | `22` nếu không đổi port              |
| `VPS_APP_DIR`  | `/opt/wholesale-portal-nest-backend` |

Không cần SSH key. Actions đăng nhập VPS bằng password.

Nếu repo GitHub private, `git pull` trên VPS cần Personal Access Token (HTTPS), không liên quan mật khẩu VPS.

## 3. Luồng sau khi setup

- Push/PR → job **Lint and build**
- Push `main` (CI xanh) → job **Deploy to VPS**

Không commit `.env`. Seed không chạy trên production (`prisma migrate deploy` only).
